# 01. 프로젝트 구조 및 실행 지침

```text
pokemon-type-alert/

│  ├─ css/
```

## 구현 메모
- 정적 화면은 `public/`에 둔다.
- Vercel 서버리스 API는 `api/`에 둔다.
- 재사용 로직은 `lib/`에 둔다.
- Supabase SQL은 `supabase/schema.sql`에 둔다.
- Vercel 배포 시 `public` 정적 파일과 `/api/*` 서버리스 함수를 함께 제공한다.
- Vercel의 Node.js 런타임과 호환되는 CommonJS 또는 프로젝트에서 일관되게 선택한 모듈 방식을 사용한다.

## 초보자용 로컬 실행 순서
1. Node.js LTS를 설치한다.
2. 프로젝트 폴더를 VS Code로 연다.
3. VS Code 메뉴에서 `터미널 > 새 터미널`을 선택한다.
4. `npm install`을 실행한다.
5. `.env.example`을 복사해 `.env` 파일을 만들고 실제 키를 입력한다.
6. `npm run dev`로 로컬 서버를 실행한다.
7. 터미널에 표시된 주소(예: `http://localhost:3000`)를 브라우저에서 연다.

## package.json 스크립트 기준
- `dev`: 로컬 개발 서버 실행
- `start`: 운영과 유사한 서버 실행(필요한 경우)
- `test`: 검증 테스트 실행

에이전트는 실제 선택한 서버 방식에 맞게 스크립트를 구현하고 README에 정확한 명령을 기록한다.
