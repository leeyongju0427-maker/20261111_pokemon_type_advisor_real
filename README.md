# 포켓몬 상성 알리미 — 프로젝트 지침 문서

이 압축 파일은 Antigravity AI 코딩 에이전트가 실제 웹앱을 구현할 때 참고하는 요구사항·작업 규칙 문서 모음입니다.

## 문서 구성
- `AGENTS.md`: 에이전트 작업 규칙
- `PRD.md`: 제품 요구사항 및 완료 기준
- `docs/01-프로젝트-구조-및-실행.md`: 폴더 구조와 로컬 실행
- `docs/02-UI-구현-지침.md`: 화면 디자인과 상태
- `docs/03-포켓몬-분석-AI-및-상성-규칙.md`: AI 역할과 상성 계산 원칙
- `docs/04-API-서버-구현-지침.md`: 서버 API 계약
- `docs/05-Supabase-데이터베이스-및-보안.md`: 피드백 DB와 보안
- `docs/06-테스트-배포-체크리스트.md`: 검증 및 Vercel 배포

## 사용 방법
1. 압축을 푼 폴더를 Antigravity에서 프로젝트 폴더로 연다.
2. 에이전트에게 “AGENTS.md, PRD.md, docs 폴더의 문서를 모두 읽고 문서의 순서와 완료 기준에 따라 구현해줘. 먼저 현재 파일을 확인하고, 불확실한 사항은 임의로 결정하지 말고 질문해줘.”라고 요청한다.
3. Supabase와 OpenAI 계정을 준비하고 실제 API 키는 로컬 `.env` 또는 Vercel 환경 변수에만 등록한다.

## 참고
현재 대화에 UI 참고 이미지가 첨부되지 않아, `docs/02-UI-구현-지침.md`에는 포켓몬 게임 도구에 어울리는 기본 디자인 방향을 정의했습니다. 실제 참고 이미지를 제공하면 해당 이미지의 레이아웃과 색상에 맞춰 수정할 수 있습니다.
